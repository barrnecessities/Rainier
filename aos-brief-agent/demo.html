How this demo works

The tracker at the top is the pipeline — like a pizza tracker, each bubble lights up as the agent moves through a stage. Same core every run; only type and posture change what comes out.
1
Pick a brief typeEach type asks the 8 context pillars differently and has its own fixed module set.
2
Pick a postureOne lens per run. It reweights emphasis, tone and depth — it never changes the module list. Try switching posture after generating: the brief re-renders instantly.
3
GenerateWatch the tracker: Intake → Data Pull → Context → Narrative → Modules → QA → Brief. The narrative is written once; modules are projections of it.
4
ConfigureAdd your own posture or brief type — new entries appear in the pickers and work immediately with placeholder content.
5
ExportDownload the logic/requirements doc, the data-sourcing map (internal / external / partner), or the raw config JSON for engineering.
