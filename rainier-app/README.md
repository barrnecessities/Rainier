# Rainier Training Dashboard

Mobile-first training dashboard for a July 5 Mount Rainier climb.

## Apps
- `frontend`: React + TypeScript + Vite UI
- `backend`: Express + TypeScript API

## Quick Start
1. Backend
   - `cd backend`
   - `npm install`
   - `npm run dev`
2. Frontend
   - `cd frontend`
   - `npm install`
   - `npm run dev`

Set backend env vars in `backend/.env` using `.env.example`.
